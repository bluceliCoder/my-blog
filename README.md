# my-blog

黎小龙的个人主页，介绍前端开发经历、项目实践与技术关注方向。

## 页面内容

- 个人介绍与技术栈
- 工作经历和项目案例
- 关于性能、跨端开发与 AI 产品的技术札记
- 联系方式

## 功能

- 响应式布局，适配桌面和移动设备
- 浅色 / 深色主题切换；首次访问时跟随系统主题，手动选择会保存在浏览器本地
- 移动端导航菜单

## 本地预览

本项目使用原生 HTML、CSS 和 JavaScript，无需安装依赖或构建。直接在浏览器中打开 `index.html` 即可预览；也可以使用任意静态文件服务器提供项目目录。

## 文件结构

```text
.
├── index.html    # 页面内容与结构
├── styles.css    # 页面样式、主题和响应式布局
├── script.js     # 主题切换与移动端导航交互
└── favicon.svg   # 浏览器标签图标
```

修改个人介绍、项目或札记内容时，请编辑 `index.html`；样式和交互分别维护在 `styles.css` 与 `script.js` 中。
